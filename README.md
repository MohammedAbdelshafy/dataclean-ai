# Veridata

Veridata is a done-for-you lead-file cleanup service. It identifies duplicate rows, standardizes supported fields and returns a separate cleaned copy with a concise report.

## What the page offers

- A request form for an initial sample
- A fixed-scope cleanup offer for customer-authorized lead files
- A separate cleaned copy and a report that explains flagged rows
- Clear reminders that customers remain responsible for lawful sourcing and outreach compliance

## Before making a delivery promise

The public page currently describes a $499 job of up to 10,000 records and a 48-hour target. Treat those as offer terms that must be confirmed with the customer and fulfillment capacity before a commitment is made. The page form is hosted separately, so verify it and the payment path end to end before claiming checkout is live.

## Important boundaries

- Preserve the customer's source file.
- Do not claim a phone number is reachable or an email is deliverable unless a supported check actually ran.
- Flag exact duplicates and inconsistent fields according to the implemented rules; do not promise fuzzy matching without testing it.
- Deliver only to an authorized customer channel.
- Do not put customer data in this repository.

The approved product name is **Veridata**. The repository slug remains `dataclean-ai` for compatibility.
