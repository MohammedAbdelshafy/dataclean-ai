# Veridata CONTEXT

One job: make a customer-authorized lead file easier to review and use, without changing the source file.

## Inputs
- Page: [index.html](index.html)
- Product notes: [README](README.md)
- Shared ICM language rules: [Jarvis ICM naming guide](https://github.com/MohammedAbdelshafy/jarvis-mbm/blob/feature/icm-portfolio-map/ICM/_shared/customer-language.md)

## Process
1. Confirm the customer's permission to process the file and the agreed fields/rules.
2. Identify duplicate rows, missing values and inconsistent formats within the implemented scope.
3. Produce a separate cleaned copy and explain exclusions and uncertain fields.
4. Keep reachability/enrichment claims separate from formatting and validation.
5. Verify sample delivery, turnaround, and payment path before publishing a firm promise.

## Output
A reviewed cleaned copy and a short QA report. The original stays unchanged.

## Check
Use a synthetic sample to check duplicate rules, required-field handling, output isolation and report clarity. Do not upload customer data to source control.
